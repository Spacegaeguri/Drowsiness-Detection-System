## 혼동행렬

행은 실제 상태, 열은 예측 상태입니다.

| 실제 / 예측 | CLOSED | OPEN | 실제 수 |
| --- | ---: | ---: | ---: |
| CLOSED | 1,566 | 0 | 1,566 |
| OPEN | 273 | 1,384 | 1,657 |

| 클래스 | Precision | Recall | F1 | Support |
| --- | ---: | ---: | ---: | ---: |
| CLOSED | 85.15498% | 100% | 91.98238% | 1,566 |
| OPEN | 100% | 83.52444% | 91.02269% | 1,657 |

표의 소수는 혼동행렬에서 계산한 값이며, 원본 `classification_report`는 CLOSED `0.85 / 1.00 / 0.92`, OPEN `1.00 / 0.84 / 0.91`처럼 소수 둘째 자리로 표시했습니다.

- Accuracy: 전체 이미지 중 맞힌 비율.
- Precision: 해당 상태라고 예측한 이미지 중 실제로 해당 상태인 비율.
- Recall: 실제 해당 상태인 이미지를 놓치지 않고 찾은 비율.
- F1: `2 × precision × recall / (precision + recall)`.

실제 CLOSED 1,566장은 모두 맞혔지만 OPEN 273장을 CLOSED로 오분류했습니다. 이 평가에서는 감긴 눈을 놓친 사례가 없고, 열린 눈의 오경보 가능성이 남아 있습니다. 이것만으로 다른 사람·실차·밤 환경에서도 감긴 눈 recall이 100%라고 주장할 수는 없습니다.

## 검증 데이터 재사용

원본은 `model.fit(..., validation_data=test_ds)`와 EarlyStopping·ModelCheckpoint에 동일 데이터를 사용하고 마지막에 `model.evaluate(test_ds)`를 수행했습니다. 데이터가 학습 gradient에 직접 들어가지는 않았지만 최적 epoch 선택에 영향을 줬으므로, 엄밀한 독립 테스트 성능이 아닙니다. 발표에는 **검증 데이터 기준 정확도 91.53%**라고 표기합니다.

또한 이 값은 CNN 단독 결과입니다. 웹에서는 기본 임계값이 0.55이며 EAR·5회 기록·양안·2초 조건이 추가됩니다. 이 수치를 전체 웹 시스템의 감지 성공률이나 경고 정확도로 사용할 수 없습니다. 원본 코드와 함께 배포된 모델 가중치에 이 Colab 수치가 그대로 재현되는지도 이번 작업에서는 재검증하지 않았습니다.
