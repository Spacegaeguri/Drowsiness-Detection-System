코드 설명

이 코드는 눈이 열린 상태와 감긴 상태를 구분하는 인공지능 모델을 학습하고, 학습된 모델을 웹브라우저에서도 사용할 수 있도록 TensorFlow.js 형식으로 변환하는 과정으로 구성되어 있다.

먼저 Kaggle에서 MRL Eye Dataset을 다운로드한다. Kaggle 명령어를 사용하기 위해 kaggle 패키지를 설치한 후, tauilabdelilah/mrl-eye-dataset 데이터셋을 다운로드하고 eye_dataset 폴더에 압축을 해제한다.

MRL Eye Dataset은 눈이 열린 이미지와 감긴 이미지로 구성되어 있으며, 이 데이터를 이용해 Open Eyes와 Close Eyes를 분류하는 모델을 학습한다.

데이터는 TensorFlow의 image_dataset_from_directory() 함수를 이용해 불러온다. 학습 데이터는 eye_dataset/data/train 폴더에서, 테스트 및 검증 데이터는 eye_dataset/data/test 폴더에서 불러온다.

모델에 입력되는 이미지의 크기는 64×64로 통일하고, RGB 3채널 이미지로 사용한다. 한 번에 학습하는 이미지 개수인 Batch Size는 32로 설정하였다.

label_mode는 binary로 설정하여 두 개의 클래스를 0과 1의 이진 값으로 처리한다. 데이터셋의 폴더 이름을 기준으로 클래스가 자동 정렬되며, 클래스 순서는 코드에서 train_ds.class_names를 출력하여 확인한다.

학습 데이터는 shuffle=True로 설정하여 학습할 때 이미지 순서를 섞고, 테스트 데이터는 shuffle=False로 설정하여 일정한 순서로 평가한다.

AUTOTUNE, cache(), prefetch()를 사용하여 데이터 처리 성능도 향상시켰다. cache()는 한 번 읽은 데이터를 재사용할 수 있도록 하고, prefetch()는 현재 학습 중인 데이터와 동시에 다음 데이터를 미리 준비하여 학습 속도를 높이는 역할을 한다.


CNN 모델 구성

눈 상태 분류 모델은 CNN(Convolutional Neural Network) 구조로 구성하였다.

첫 번째 Rescaling 레이어에서는 이미지의 픽셀 값을 255로 나누어 0~1 범위로 정규화한다.

입력 이미지의 크기는 64×64×3이다.

그다음 Conv2D와 MaxPooling2D 레이어를 세 번 반복한다.

첫 번째 Conv2D 레이어는 32개의 필터를 사용한다.
두 번째 Conv2D 레이어는 64개의 필터를 사용한다.
세 번째 Conv2D 레이어는 128개의 필터를 사용한다.

각 Conv2D 레이어에는 ReLU 활성화 함수를 사용한다.

각 합성곱 레이어 뒤에는 MaxPooling2D를 배치한다. Max Pooling은 CNN에서 추출된 특징 중 중요한 정보는 유지하면서 데이터의 크기를 줄이는 역할을 한다.

세 번의 합성곱과 Pooling 과정을 거친 후 GlobalAveragePooling2D를 사용한다. 이 레이어는 각 Feature Map의 평균값을 계산하여 CNN에서 추출된 특징을 1차원 형태로 변환한다.

그다음 Dense 레이어를 배치하고 64개의 뉴런과 ReLU 활성화 함수를 사용한다.

Dropout은 0.4로 설정하였다. 학습 중 일부 뉴런을 임의로 비활성화하여 특정 데이터에 과도하게 맞춰지는 과적합을 줄이는 역할을 한다.

마지막 출력 레이어는 Dense(1)로 구성하고 Sigmoid 활성화 함수를 사용한다.

Sigmoid 함수는 0과 1 사이의 값을 출력하기 때문에 두 가지 눈 상태를 분류하는 Binary Classification에 사용할 수 있다.


모델 컴파일

모델의 Optimizer는 Adam을 사용하였다.

Loss Function은 Binary Crossentropy를 사용하였다.

눈이 열린 상태와 감긴 상태 두 가지를 구분하는 이진 분류 문제이기 때문에 Binary Crossentropy를 사용한다.

모델의 평가 지표는 Accuracy로 설정하였다.


모델 학습

모델은 최대 15 Epoch 동안 학습하도록 설정하였다.

학습 과정에서는 EarlyStopping과 ModelCheckpoint를 사용한다.

EarlyStopping은 validation loss를 기준으로 모델의 성능을 확인한다.

validation loss가 3번 연속으로 개선되지 않으면 학습을 조기에 종료한다.

restore_best_weights=True로 설정하였기 때문에 학습 종료 시 가장 좋은 성능을 보였던 시점의 가중치로 복원된다.

ModelCheckpoint도 validation loss를 기준으로 가장 좋은 모델만 저장하도록 설정하였다.

가장 성능이 좋은 모델은 다음 파일로 저장된다.

best_eye_model.keras

따라서 학습이 끝난 마지막 모델을 사용하는 것이 아니라 validation loss가 가장 좋았던 모델을 최종적으로 사용할 수 있다.


학습된 모델 불러오기

학습이 끝난 후 best_eye_model.keras 파일을 다시 불러온다.

이때 compile=False로 설정하여 학습 설정을 다시 불러오지 않고 모델 구조와 가중치만 불러온다.


새 모델 구성

기존 학습 모델을 웹에서 사용할 수 있는 형태로 변환하기 전에 새로운 Sequential 모델을 만든다.

새로운 모델에는 입력 크기를 다음과 같이 명확하게 지정한다.

64×64×3

그리고 학습된 old_model을 새로운 Sequential 모델 내부에 포함한다.

그다음 다음 형태의 임의 입력 데이터를 한 번 전달한다.

1×64×64×3

이를 통해 모델의 Input Shape와 Output Shape가 명확하게 생성되도록 한다.


TensorFlow.js 형식 변환

학습된 Keras 모델은 그대로는 JavaScript 환경에서 사용할 수 없기 때문에 TensorFlow.js 형식으로 변환한다.

tensorflowjs 라이브러리의 save_keras_model() 함수를 이용하여 새 모델을 model 폴더에 저장한다.

변환이 완료되면 일반적으로 다음과 같은 파일이 생성된다.

model.json
group1-shard1of1.bin

model.json에는 모델 구조와 레이어 정보가 저장된다.

bin 파일에는 학습된 모델의 Weight 값이 저장된다.

두 파일은 함께 사용해야 하나의 TensorFlow.js 모델로 동작한다.


모델 압축

마지막으로 model 폴더 전체를 zip 파일로 압축한다.

생성되는 압축 파일의 이름은 다음과 같다.

eye_model_tfjs.zip

이 파일 안에는 TensorFlow.js 형식으로 변환된 모델 파일들이 포함된다.
